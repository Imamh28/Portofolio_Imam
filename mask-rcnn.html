Emphysema Lesion Detection & Segmentation

Bachelor thesis project focused on pulmonary emphysema lesion segmentation from chest X-ray images using Mask R-CNN deep learning architecture for computer-aided medical diagnosis.

Problem Statement

Pulmonary emphysema is a chronic lung disease that causes damage to air sacs in the lungs and reduces respiratory function. Manual lesion identification from chest X-ray images requires experienced radiologists and can be time-consuming.

Research Objective

This research aims to develop an automated medical imaging system capable of detecting and segmenting emphysema lesion areas using deep learning techniques to support faster and more accurate diagnosis.

Methodology

The system was developed using Mask R-CNN architecture with ResNet backbone for object detection and image segmentation. Chest X-ray images were resized into 512×512 resolution before annotation and training processes.

Data Annotation

Image annotation was conducted using VIA Annotator to create segmentation masks for emphysema lesions. The annotations were validated by radiology experts to ensure data quality and medical accuracy.

Development Workflow

The project workflow includes data preprocessing, annotation, model training, validation, and evaluation. Image preprocessing was performed to normalize datasets and improve training consistency.

Model Evaluation

The model performance was evaluated using segmentation metrics such as accuracy, precision, recall, and IoU (Intersection over Union) to measure the quality of lesion detection and segmentation results.
